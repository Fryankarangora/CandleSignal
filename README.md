# CandleSignal

CandleSignal is a data-driven platform for real-time market analysis, automated signal detection and API integration for informed decision-making.

CandleSignal is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/CandleSignal.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure CandleSignal, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
